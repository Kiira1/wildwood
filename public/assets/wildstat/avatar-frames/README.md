# Supporter frame artwork

`supporter.png` is the original transparent `Large/ProfileFrame_01_BorderDeco_Gold.png`
from the user-provided **2D Avatar Frame.zip**. Its bytes match the PNG in
**GUI - Avatar Frame.unitypackage**. The game uses the PNG directly; Unity is not
required to render it.

Gold uses the original colors. Silver uses a grayscale/brightness CSS filter.
The image overlays the portrait and does not alter its dimensions or click area.
